Gunsout: Composite Design across Color Styles

The same composite usability design (Bento base, Diet as gauges, Today / Body / Settings as cards) rendered in each of the 6 color styles. Toggle rows to compare; horizontal scroll is synced so every style lines up screen-for-screen.

Static mockup. Vanilla HTML/CSS/JS, no build step. The composite usability layout is defined once; each row paints it in a different color style (palette, gradient, shading, corner and shadow language) applied via CSS custom properties.
